# Security

[docs/threats.md](docs/threats.md) lists what KeyHandoff does and doesn't protect against, with the test or design rule behind each claim. The design is written up for peer review in [a paper](paper/paper.pdf), and [eval/run.sh](eval/run.sh) lets anyone rerun every measured result.

To report a vulnerability, email junovhs@gmail.com rather than opening a public issue. Please don't include real keys or other live secrets in a report.
